# Connect v1.0.0-preview.20

This preview lets you approve managed VPC networking once per device. The
helper stores a constrained client policy, so later compliant VPC joins do not
ask for administrator approval again. The first approval lists the address,
routes, MTU, and attachment limits. Direct peer and route-advertising
attachments still require exact approval.

If Connect finds an older installed networking helper, `datumctl connect join`
explains that it must upgrade the helper and asks before disconnecting active IP
attachments. Services and local ports continue running.

Install the plugin and daemon with the
[manual installation guide](../INSTALL.txt). Sign in with `datumctl login`, then
join a VPC and access a running endpoint:

```sh
datumctl connect join my-network --project my-project
curl -g -i 'http://[fd20:0:27::1:0:0]:8080/'
```

Replace the project, network, IPv6 address, and port with your values. The join
command creates or reuses a gateway in the nearest Datum location. Your project
must have a default `ConnectGatewayClass`, a Ready `ConnectorClass` that
supports MASQUE, and permission to create Connect resources. The VPC firewall
must allow the traffic.
