# Connect v1.0.0-preview.20

Connect remembers your administrator approval for managed VPC networking on each device. Review the constrained policy once; future compatible VPC joins on that device do not need administrator access. Direct peer and route-advertising connections still require approval.

If Connect needs to upgrade an older networking helper, it asks first. Active IP attachments disconnect during the upgrade, but services and local ports keep running.

Install the plugin and daemon with the [manual installation guide](../INSTALL.txt). Sign in with `datumctl login`, then join a VPC and access a running endpoint:

```sh
datumctl connect join my-network --project my-project
curl -g -i 'http://[fd20:0:27::1:0:0]:8080/'
```

Replace the project, network, IPv6 address, and port with your values. Connect creates or reuses a gateway in the nearest Datum location. Your project must allow Connect access, and the VPC firewall must allow traffic to the endpoint.
