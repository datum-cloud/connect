# Connect v1.0.0-preview.22

This preview fixes managed VPC joins after you approve the one-time networking
policy. The daemon now checks each attachment against that saved policy instead
of requiring a separate exact approval. It also restores Windows builds.

Upgrade the Connect plugin and daemon. If you already approved the managed
policy, retry the join:

```sh
datumctl connect join my-network --project my-project
```

The helper still limits addresses, routes, and interfaces to the approved
managed networking policy.
