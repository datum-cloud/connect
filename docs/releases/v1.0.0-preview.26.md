# Datum Connect v1.0.0-preview.26

This preview restores the complete managed VPC join flow. Given an existing
Network, `datumctl connect join NETWORK` selects an existing ConnectGateway or
creates one automatically in the nearest Datum location using the project's
Ready default ConnectGatewayClass. It can bind while an OnDemand gateway is
provisioning and reports the selected gateway and location in join and status
output.

## Install on macOS or Linux

Paste this into bash:

```sh
bash -c 'set -e; v=v1.0.0-preview.26; os=$(uname -s); case "$os" in Darwin|Linux) ;; *) echo "unsupported OS: $os" >&2; exit 1;; esac; arch=$(uname -m); case "$arch" in x86_64|amd64) arch=x86_64;; arm64|aarch64) arch=arm64;; *) echo "unsupported architecture: $arch" >&2; exit 1;; esac; asset="datumctl-connect_${os}_${arch}.tar.gz"; mkdir -p "$HOME/.local/bin"; curl -fsSL "https://github.com/datum-cloud/connect/releases/download/$v/$asset" | tar -xz -C "$HOME/.local/bin" datumctl-connect datum-connectd datum-connect-network-helper; export PATH="$HOME/.local/bin:$PATH"; datumctl plugin trust connect; datumctl connect version'
```

Add `~/.local/bin` to `PATH` in your shell startup file if needed. The release
asset `INSTALL.txt` also contains the detailed manual and troubleshooting flow.

## Join a VPC

Sign in to staging and select the project that owns the Network:

```sh
datumctl login --hostname auth.staging.env.datum.net
datumctl connect join NETWORK --project PROJECT
curl -g -i 'http://[INSTANCE_IPV6]:PORT/'
```

The Connect service must be enabled with one Ready default ConnectGatewayClass,
and your account must be allowed to create ConnectGateway and
ConnectNetworkBinding resources. The VPC firewall must allow the target traffic.

This release also restores automatic upgrades for older networking helpers,
canonical Connect collection requests, operator relay selection, and clear
provisioning diagnostics for managed joins.
