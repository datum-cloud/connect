# Connect v1.0.0-preview.3

This preview fixes staging relay setup, enrollment errors, and the instructions printed when you share a service.

## Install on your Mac

You need `datumctl` installed and access to the shared staging project. Both people run this once, then use the same terminal for the commands below:

```sh
CONNECT_DIR="$HOME/.local/share/datum-connect/previews/v1.0.0-preview.3"
mkdir -p "$CONNECT_DIR"
curl -fL "https://github.com/datum-cloud/connect/releases/download/v1.0.0-preview.3/datumctl-connect_Darwin_$(uname -m).tar.gz" | tar -xz -C "$CONNECT_DIR"
export PATH="$CONNECT_DIR:$PATH"
export DATUMCTL_PLUGINS_DIR="$CONNECT_DIR/plugin-registry"
datumctl plugin trust connect
datumctl login --hostname auth.staging.env.datum.net
```

This works on Apple Silicon and Intel Macs. The separate plugin registry selects this preview without replacing your usual plugin installation.

Already running an earlier preview? Follow the [upgrade instructions](https://github.com/datum-cloud/connect/releases/download/v1.0.0-preview.3/INSTALL.txt) too: replacing the plugin does not upgrade the daemon.

## Share your app

Start your app on port 8080, then run:

```sh
datumctl connect serve localhost:8080 --project datum-cloud
```

Accept the setup prompts. Connect installs its background daemon and connects your device automatically. Send your friend the `datumctl connect dial …` command printed by `serve`.

## Connect to your friend's app

After installing above, connect your device once:

```sh
datumctl connect up --project datum-cloud
```

Then run the `dial` command your friend sent you. Open the local address it prints in your browser. The service is private to your shared project.

Replace `datum-cloud` in these commands if you use a different shared project.

See [INSTALL.txt](https://github.com/datum-cloud/connect/releases/download/v1.0.0-preview.3/INSTALL.txt) for other platforms, checksums, persistent shell setup, upgrades, and troubleshooting. Mac preview binaries are unsigned and unnotarized.
