# Connect v1.0.0-preview.15

This preview adds managed Connect VPC joins through `ConnectGateway` and
`ConnectNetworkBinding`. Follow the [installation guide](../INSTALL.txt) to
install the plugin and daemon. Section 7 describes how to join a VPC and reach
an existing Compute instance by its VPC IPv6 address.

## Before you connect

A project administrator must install the Connect API/controller, configure a
compatible `ConnectorClass`, and deploy a Ready `ConnectGateway` for the target
VPC. Its routes must include the Compute instance's VPC IPv6 address. Your
account must be allowed to enroll a Connector and create a
`ConnectNetworkBinding`. The instance must listen on the requested port, and
the VPC firewall must allow traffic from the gateway. The CLI does not create
the VPC or gateway.

Use a project where your account can create its `ConnectNetworkBinding`:

```sh
datumctl login --hostname auth.staging.env.datum.net
datumctl connect join staging-vpc --project my-project
```

On first use, Connect asks before it installs the local networking helper and
adds the displayed routes. Review the route list before approving it. After
`join` reports a connected attachment, access the running instance directly:

```sh
curl -g -i 'http://[fd20:0:27::1:0:0]:8080/'
```

Replace the example network, project, address, and port with your values. The
address in the URL must be the instance's VPC address, not its public address.
The VPC firewall and the instance's listener still control access. This flow
does not publish the instance to the public internet.

The host interface and routes do not survive a daemon restart. Run `join` again
to reattach. Run this command to leave and remove the binding:

```sh
datumctl connect leave staging-vpc --project my-project
```

This managed VPC path is a staging preview. It requires a compatible Connect
controller, gateway image, Compute runtime, and relay configuration. It supports
IPv6 VPC routes; it does not support arbitrary site-to-site transit. For the
separate static peer-to-subnet prototype, use
[`STAGING_SUBNET_LAB.md`](../../scripts/STAGING_SUBNET_LAB.md).
