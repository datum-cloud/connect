# Connect v1.0.0-preview.15

This preview lets you connect a device to a Datum VPC and reach an existing
Compute instance over its private VPC address. Install the plugin and daemon
using the [installation guide](../INSTALL.txt), then follow this flow.

## Before you connect

A project administrator must install the Connect API/controller, configure a
compatible `ConnectorClass`, and deploy a Ready `ConnectGateway` for the target
VPC. Its routes must include the Compute instance's VPC IPv6 address. Your
account must be allowed to enroll a Connector and create a
`ConnectNetworkBinding`. The instance must listen on the requested port, and
the VPC firewall must allow traffic from the gateway. The CLI does not create
the VPC or gateway.

Ask your project administrator for the project and network name, the Compute
instance's VPC IPv6 address and application port, and confirmation that the
gateway is ready and the VPC firewall allows the traffic. Sign in to the
environment that owns the project, then join the network:

```sh
datumctl login --hostname auth.staging.env.datum.net
datumctl connect join staging-vpc --project my-project
```

On first use, Connect asks before it installs the local networking helper and
adds the displayed routes. Review the route list before approving it. After
`join` reports that you are connected, send a request to the instance's VPC
IPv6 address and listening port:

```sh
curl -g -i 'http://[fd20:0:27::1:0:0]:8080/'
```

Replace the example network, project, address, and port with the values for
your environment. Keep the square brackets around an IPv6 address in a URL.
Use the instance's VPC address, not its public address. The application must
be listening on that port, and the VPC firewall must allow the traffic. This
flow gives your device private VPC access; it does not publish the instance to
the public internet.

If the request times out, first check `datumctl connect status` to confirm the
attachment is connected. Then ask the administrator to verify the gateway's
route to the instance and its readiness. Also check that the instance is
listening on the requested port and that the VPC firewall allows traffic.

The host interface and routes do not survive a daemon restart. Run `join` again
to reattach. Run this command to leave and remove the binding:

```sh
datumctl connect leave staging-vpc --project my-project
```

This managed VPC path is a staging preview. It requires a compatible Connect
controller, gateway image, Compute runtime, and relay configuration. It supports
IPv6 VPC routes; it does not support arbitrary site-to-site transit. For the
separate static peer-to-subnet prototype, use
[`STAGING_SUBNET_LAB.md`](../../scripts/STAGING_SUBNET_LAB.md).
