# Datum Connect v1.0.0-preview.28

Datum Connect is a background networking agent for your Datum projects. It
enrolls your device, maintains its private connector identity and sessions,
lets teammates reach services running on your machine, and attaches the device
to managed VPCs.

This preview fixes automatic managed gateway placement. Connect now uses the
fully qualified Compute location name returned by the nearest edge, such as
`us-central-1`, instead of an edge colo code such as `DAL`. Existing gateways
with a colo code in `spec.locationRef` must be corrected by a project operator.

## Install on macOS or Linux

Paste this into bash:

```sh
bash -c 'set -e; v=v1.0.0-preview.28; os=$(uname -s); case "$os" in Darwin|Linux) ;; *) echo "unsupported OS: $os" >&2; exit 1;; esac; arch=$(uname -m); case "$arch" in x86_64|amd64) arch=x86_64;; arm64|aarch64) arch=arm64;; *) echo "unsupported architecture: $arch" >&2; exit 1;; esac; asset="datumctl-connect_${os}_${arch}.tar.gz"; mkdir -p "$HOME/.local/bin"; curl -fsSL "https://github.com/datum-cloud/connect/releases/download/$v/$asset" | tar -xz -C "$HOME/.local/bin" datumctl-connect datum-connectd datum-connect-network-helper; export PATH="$HOME/.local/bin:$PATH"; datumctl plugin trust connect; datumctl connect version'
```

## Install on Windows

Paste this into PowerShell:

```powershell
$ErrorActionPreference='Stop'; $v='v1.0.0-preview.28'; $arch=switch([Runtime.InteropServices.RuntimeInformation]::OSArchitecture.ToString()){'X64'{'x86_64'} 'Arm64'{'arm64'} default {throw "Unsupported architecture: $([Runtime.InteropServices.RuntimeInformation]::OSArchitecture)"}}; $dir=Join-Path $HOME '.local\bin'; New-Item -ItemType Directory -Force -Path $dir | Out-Null; $zip=Join-Path $env:TEMP "datumctl-connect-$v.zip"; Invoke-WebRequest -UseBasicParsing "https://github.com/datum-cloud/connect/releases/download/$v/datumctl-connect_Windows_$arch.zip" -OutFile $zip; Expand-Archive -Force $zip $dir; $env:PATH="$dir;$env:PATH"; datumctl plugin trust connect; datumctl connect version
```

Add the install directory to your persistent `PATH` if needed. Windows daemon
service setup still requires an elevated PowerShell; see `INSTALL.txt` in the
release assets for the platform details.

## Connect to a VPC

```sh
datumctl connect join NETWORK --project PROJECT
```

Connect selects the nearest Datum location and creates the managed
ConnectGateway automatically when the Network does not already have one.

## Expose a local service

On the machine running the application:

```sh
datumctl connect serve localhost:8080 --project PROJECT
```

On another connector in the same project:

```sh
datumctl connect dial CONNECTOR:8080 --bind 18080 --project PROJECT
curl http://localhost:18080
```

Services are private to the project by default. Use the exact connector name
and dial command printed by `serve` or shown by `datumctl connect status`.
