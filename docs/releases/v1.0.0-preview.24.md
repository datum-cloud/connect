# Datum Connect v1.0.0-preview.24

This preview upgrades the standard macOS/Linux user-service daemon automatically when you run `datumctl connect join`, `up`, `serve`, or `install` with a different plugin release. The upgrade preserves daemon state and service settings, verifies readiness, and restores the previous service definition if the new daemon fails to start. Active tunnels briefly disconnect during the restart.

## Install

Download the matching macOS or Linux archive from this release and extract it into a directory on your `PATH`. Keep `datumctl-connect` and `datum-connectd` together. Then run `datumctl plugin trust connect` and `datumctl connect version`.

## Join a VPC

Sign in to the staging environment and select the project that owns a Ready ConnectGateway:

```sh
datumctl login --hostname auth.staging.env.datum.net
datumctl connect join NETWORK --project PROJECT
curl -g -i 'http://[INSTANCE_IPV6]:PORT/'
```

Replace `NETWORK`, `PROJECT`, `INSTANCE_IPV6`, and `PORT` with the values for your VPC and running Compute instance. The gateway must advertise a route to the instance, and VPC firewall rules must allow the connection. See `INSTALL.txt` in the release assets for platform-specific installation and troubleshooting.
