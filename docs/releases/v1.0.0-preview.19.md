# Connect v1.0.0-preview.19

This preview reports the running daemon release in `datumctl connect health`.
Use it to confirm that the daemon matches the plugin before troubleshooting a
connection.

Install the plugin and daemon with the
[manual installation guide](../INSTALL.txt). Sign in with `datumctl login`,
then join a VPC and access a running endpoint:

```sh
datumctl connect join my-network --project my-project
curl -g -i 'http://[fd20:0:27::1:0:0]:8080/'
```

Replace the project, network, IPv6 address, and port with your values. A project
administrator must configure a ready Connect gateway and allow the traffic in
the VPC firewall. Run `datumctl connect health` to check the local daemon.
